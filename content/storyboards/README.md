# 자체 제작 모션 설명 스토리보드

각 트랙은 6컷 × 8초, 총 48초다. 실제 재생 장면·한국어 자막·대본의 단일 원본은 [`../concepts.json`](../concepts.json)이다. 외부 영상, 이미지, 음원, 자막을 사용하지 않는다. 화면은 CSS 도형과 SVG 경로만으로 렌더링하며 원본은 무음이다.

2026년 추가 트랙 11개의 제작 컷은 [`expansion-2026.md`](expansion-2026.md)에 정리되어 있다.

## 스택 — 괄호의 위쪽 박자

1. 접시처럼 위로 쌓이는 값
2. 마지막 값이 먼저 나오는 LIFO
3. 여는 괄호 push
4. 닫는 괄호와 top 비교
5. 빈 스택으로 종료
6. 문자당 한 연산, O(n)

## 큐 — 먼저 온 박자부터

1. 뒤로 들어오는 새 작업
2. 앞에서 처리하는 FIFO
3. front 상태 변화
4. 완료 작업 dequeue
5. 용량 초과 입력 무시
6. 도착 순서 보존

## 해시맵 — 이름표가 붙은 서랍

1. 키를 위치 후보로 변환
2. 기존 키의 값 갱신
3. 문자열 빈도 누적
4. 충돌이 가능한 이유
5. 최빈값과 동률 규칙
6. 평균 O(1) 조회

## 이진 탐색 — 반으로 줄이는 박자

1. 정렬 전제
2. 중앙 값 확인
3. 불필요한 절반 제거
4. 답 후보를 남기고 왼쪽 탐색
5. 두 경계가 만나는 하한
6. O(log n)

## 병합 정렬 — 나누고 다시 섞기

1. 배열 반 분할
2. 원소 하나의 기저 조건
3. 두 정렬 줄의 앞 비교
4. 동률에서 왼쪽 우선
5. 남은 원소 병합
6. O(n log n), O(n) 공간

## BFS — 파동처럼 가까운 곳부터

1. 시작점을 큐에 삽입
2. 가까운 이웃 확인
3. 큐 삽입 시 방문 표시
4. 거리 층의 확장
5. 동일 가중치에서 첫 도착이 최단
6. O(V+E)

## DFS — 한 갈래 끝까지

1. 미방문 이웃 선택
2. 진입 즉시 방문 표시
3. 막히면 이전 갈림길로 복귀
4. 한 연결 덩어리 완주
5. 새 미방문 정점에서 재시작
6. 깊은 입력에는 명시적 스택

## 기초 DP — 작은 답을 이어 붙이기

1. `dp[i]` 상태 정의
2. 마지막 이동 선택
3. 이전 답 두 개 재사용
4. 의존 순서대로 표 채우기
5. 경계 초깃값
6. 중복 제거로 O(n)

## 덱 — 양쪽에서 이어지는 박자

1. 앞과 뒤 두 출입구
2. 앞에 값 삽입
3. 뒤에 값 삽입
4. 앞 값 제거
5. 뒤 값 제거
6. 양끝 연산 O(1)

## 연결 리스트 — 링크를 바꾸는 편집

1. 값과 이웃 연결을 가진 노드
2. 노드 사이의 커서
3. 이전 연결로 이동
4. 새 노드를 사이에 연결
5. 삭제 노드를 건너뛰어 연결
6. 위치를 알 때 삽입·삭제 O(1)

## 최소 힙 — 가장 작은 박자를 루트로

1. 루트의 최솟값
2. 완전 이진 트리 끝에 삽입
3. 부모와 비교하며 올리기
4. 루트 제거
5. 작은 자식과 비교하며 내리기
6. 삽입·제거 O(log n)

## 서로소 집합 — 대표로 연결 확인

1. 각자 자기 자신을 대표로 시작
2. 부모를 따라 대표 찾기
3. 서로 다른 두 집합 합치기
4. 작은 트리를 큰 트리 아래에 연결
5. find 경로 압축
6. 대표 비교로 같은 집합 판정

## 접근성·연출 원칙

- 장면의 핵심 설명을 항상 텍스트 자막과 전체 대본으로 제공한다.
- 입력 중 점멸, 카운트다운, 자동 음향, 순위, 실패 진동을 사용하지 않는다.
- `prefers-reduced-motion`에서 노드 이동 전환을 제거한다.
- 자막 토글과 속도 선택은 키보드로 조작 가능하며 현재 장면은 `aria-live`로 알린다.
