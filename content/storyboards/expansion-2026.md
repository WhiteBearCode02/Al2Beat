# 2026 콘텐츠 확장 스토리보드

각 트랙은 6컷 × 8초, 총 48초이며 실제 자막과 대본의 단일 원본은 [`../concepts.json`](../concepts.json)입니다.

## 배열과 문자열 — 연속 구간 압축

1. 첫 문자와 횟수 1 준비
2. 다음 문자와 현재 문자 비교
3. 같은 문자의 횟수 증가
4. 문자가 바뀔 때 이전 구간 기록
5. 반복 종료 뒤 마지막 구간 기록
6. 한 번의 순회와 O(1) 보조 상태

## 누적 합 — 앞부분 합의 차

1. 비어 있는 앞부분 prefix[0]
2. 왼쪽부터 합 누적
3. 구간의 두 경계 선택
4. 오른쪽 합에서 왼쪽 이전 합 제거
5. 여러 질의를 두 배열 값으로 처리
6. O(n) 전처리와 O(1) 질의

## 투 포인터 — 양끝의 목표 합

1. 정렬 배열 양끝에 포인터 배치
2. 현재 두 값의 합 계산
3. 작은 합에서 left 이동
4. 큰 합에서 right 이동
5. 목표 합 또는 포인터 교차
6. 한 방향 이동으로 O(n)

## 슬라이딩 윈도우 — 유효한 가장 긴 창

1. 빈 윈도우 준비
2. right 확장과 빈도 증가
3. 서로 다른 문자 수 확인
4. 조건을 회복할 때까지 left 축소
5. 유효한 구간의 최대 길이 갱신
6. 각 문자의 진입·이탈 한 번씩

## 재귀와 백트래킹 — 선택하고 복구하기

1. 현재 깊이의 미사용 수 선택
2. 방문 표시와 경로 추가
3. 다음 깊이 재귀 호출
4. 길이 r에서 순열 출력
5. 경로와 방문 상태 복구
6. 탐색 트리의 다른 가지 진행

## 그리디 — 큰 동전부터

1. 남은 금액 이하의 가장 큰 동전
2. 몫만큼 한꺼번에 선택
3. 나머지 금액 갱신
4. 다음 작은 동전으로 이동
5. 정해진 동전 체계의 최적성
6. 임의 동전 체계의 반례 경고

## 이진 트리 — 레벨별 높이

1. 루트에서 시작
2. 왼쪽·오른쪽 자식 연결
3. 현재 레벨을 큐에 배치
4. 다음 레벨의 자식 수집
5. 레벨 종료마다 높이 증가
6. 전체 노드를 한 번 방문

## 이진 탐색 트리 — 범위를 내려 보내기

1. 루트의 열린 전체 범위
2. 왼쪽 자식의 위 경계 갱신
3. 오른쪽 자식의 아래 경계 갱신
4. 조상 경계를 서브트리에 전달
5. 중복 또는 범위 위반 감지
6. 명시적 스택으로 O(n) 검사

## 다익스트라 — 가장 가까운 후보부터

1. 시작점 0과 나머지 무한대
2. 최소 힙에서 가장 가까운 후보 추출
3. 오래된 거리 항목 무시
4. 인접 간선 완화
5. 개선된 거리 다시 삽입
6. 음수 간선을 허용하지 않는 이유

## 위상 정렬 — 준비된 작업의 순서

1. 모든 정점의 진입 차수 계산
2. 진입 차수 0을 최소 힙에 배치
3. 가장 작은 작업 출력
4. 나가는 간선을 제거하듯 차수 감소
5. 새로 준비된 작업 삽입
6. 모든 정점 처리와 DAG 조건

## 배낭 동적 계획법 — 용량을 뒤에서부터

1. 용량별 최대 가치 상태
2. 현재 물건을 선택하지 않는 경우
3. 선택하는 경우의 후보 가치
4. 두 값의 최댓값 저장
5. 중복 선택을 막는 역방향 갱신
6. O(nW) 시간과 O(W) 공간
